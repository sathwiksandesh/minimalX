#  MinimalX

### Modern SaaS Productivity Landing Page

MinimalX is a modern, responsive **SaaS landing page** designed for a next-generation productivity platform. It presents AI-powered automation, analytics, collaboration, security, and productivity features through a clean and engaging user interface.

The project is built from scratch using **HTML, CSS, and vanilla JavaScript**, with a focus on responsive design, smooth interactions, usability, and modern SaaS-style aesthetics.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/sathwiksandesh/minimalX.git
```

### 2. Navigate to the project

```bash
cd minimalX
```

### 3. Run locally

Since MinimalX is a static frontend project, no backend or package installation is required.

You can simply open:

```text
index.html
```

in your browser.

For a better development experience, use the **Live Server** extension in Visual Studio Code.
